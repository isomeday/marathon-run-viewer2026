# マラソンランビューワー

Marathon Run Viewer

ランニングウォッチの走行記録ファイル(fitファイル)を読み込んで、1kmごとのペースや心拍を、複数の記録で重ねてグラフで比べる、マラソン・ランニングの記録比較ツールです。

**▶ アプリを開く: https://isomeday.github.io/marathon-run-viewer2026/**


## できること

- ランニングウォッチの fitファイルを読み込みます。fitファイルが入った zipファイルも、そのまま読み込めます(複数まとめて入れられます)
- 1kmごとのペースを、記録ごとに色分けして重ねたグラフで比べられます(記録は10件まで)
- グラフに指やマウスを当てると、その区間のペース・心拍・みなし停止の時間を表示します
- 平均心拍を、点線でグラフに重ねられます
- 記録一覧に、計測距離・時間・平均心拍・みなし停止時間・平均ペース・後半と前半の差を表示します
- 平均ペースの計算に使う距離を、記録ごとに選べます(フルマラソン・ハーフマラソン・計測距離を使う・任意指定)。取り込んだときは、計測距離に合わせて自動で選びます
- トイレやエイドなどで止まっていた時間(みなし停止)を除いた平均ペースも出せます
- 開始直後にランニングウォッチが実際より高く表示した心拍を、平均心拍の計算から除きます
- 日付は、記録した場所の日付で表示します
- パソコンでもスマートフォンでも使えます

## 使い方

1. 上のリンクを開きます(インストールや登録は不要です)
2. fitファイル(または fitファイル入りの zipファイル)を、「記録を追加」の枠にドラッグするか、「ファイルを選ぶ」で選びます
3. 記録一覧で、名前を書き換えたり、「計算に使う距離」を確かめたりします
4. グラフで記録を比べます。凡例のチェックを外すと、その記録をグラフから隠せます。「みなし停止時間を除く」にチェックを入れると、止まっていた時間を除いたペースに切り替わります

画面の項目の意味は、「使い方の説明」ボタンで確認できます。

## 主な仕様

- **計算に使う距離**
  - フルマラソン(42.195km)・ハーフマラソン(21.0975km): 記録全体の時間を、大会の正式な距離で割って、平均ペースを出します
  - 計測距離を使う: 記録全体の時間を、計測距離で割ります。ウルトラや、フル・ハーフ以外の距離のときに使います
  - 任意指定(1.0〜99.9km): スタートから、指定した距離の地点までで計算します
  - 取り込んだときは、計測距離が41.0〜44.0kmならフルマラソン、20.5〜22.5kmならハーフマラソン、それ以外は計測距離を使う、を自動で選びます。あとから変えられます
- **みなし停止**: 設定した速さ(初期値は時速2.0km未満)より遅い状態が10秒以上続いた時間を、みなし停止時間とします。途中の短いふらつき(3秒以内・2m以内)は、続いているとみなします。停止とみなす速さは、時速0.5〜4.0kmの間で変えられます
- **後半−前半**: 計測距離の半分の地点で分けて、前半と後半の時間を比べます。みなし停止の時間も含めます。「+」の場合、後半の方が遅かったことを表します
- **平均心拍**: 開始から15分までの間に、その後の安定した心拍(15〜40分の中央値)より10以上高い値があれば、その値を除いて計算します

## fitファイルの取り出し方(参考)

※2026年10月時点で、個人的に調べた参考情報です。メーカーの公式見解ではありません。手順は変わることがあるので、最新の情報は各メーカーのサイトでご確認ください。

- **ガーミン**: パソコンで Garmin Connect から操作します。ダウンロードした zipファイルは、解凍せずにそのまま読み込めます。手順は、日本語で分かりやすい Strava のヘルプページが参考になります: https://support.strava.com/ja/articles/15402167-garmin-connect
- **COROS**: COROSアプリのデータのエクスポート機能で、ファイル形式に「FITファイル(.fit)」を選びます
- **Suunto**: スマートフォンの Suuntoアプリで、アクティビティ(トレーニング記録)から「FITファイルをエクスポート」を選びます

どなたでも無料でお使いいただけます。アカウント登録も広告もありません。

## 読み込んだ記録の扱い

- 読み込んだファイルは、お使いのブラウザの中だけで処理され、サーバーなど外部に送ることはありません
- 取り込んだ記録は、お使いのブラウザの中(localStorage)にだけ保存されます。位置情報は保存しません
- 保存した記録は、「行削除」や「記録をすべて削除する」で消せます(元の fitファイルは消えません)
- 画面の文字を表示するために、Google Fonts を読み込んでいます(ページを開く際、お使いの端末のIPアドレスなどがGoogleに送信されます)

## ソースコードについて

アプリは、`index.html` の1ファイルだけで動いています(HTML・CSS・JavaScript)。外部のライブラリは使っていません。zipファイルの解凍には、ブラウザに元々ある機能を使っています。

ブラウザで右クリックして「ページのソースを表示」を選ぶと、中身を確認できます。このリポジトリの `index.html` と同じものです。

## ご注意

- 非公式の、個人が作ったツールです。ランニングウォッチのメーカーとは関係ありません
- 計算結果は目安です。ご利用は自己責任でお願いします
- 「計測距離」は、ランニングウォッチ(fitファイル)の記録です。大会の正式な距離より長くなることも短くなることもあり、公式記録とずれが生じる場合があります
- 「時間」は、ランニングウォッチの記録上の経過時間です。自動停止(オートポーズ)を使った記録では、その停止時間も含まれるため、ランニングウォッチ本体に表示される時間と異なることがあります
- 選んだ「計算に使う距離」が記録と合っていないと(たとえば10kmの記録でフルマラソンを選ぶと)、平均ペースが大きく外れます
- ランニングウォッチの機種や設定によっては、正しく読み込めない場合があります
